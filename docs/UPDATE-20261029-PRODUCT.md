# 图片、素材与设置视图更新

图片外发授权与单个合成自检解耦。用户可明确选择接收接口后开启图片输入，自检失败仍如实保留，不伪造模型能力。专业诊断支持同色序的尺寸/精度对照；尚未替真实上游的识别质量作保证。

增加本地图片/GIF素材库与独立发送范围、频率和数量设置。默认不发送、不自动附图，未导入素材不会自动收集图片。新增投递记录、重复操作去重、排队取消、未知结果保护和迟到回执确认；不把商城表情等同于普通GIF。

默认简易模式，专业模式保留完整配置与诊断。增加可选筛查独立保存，修正本地语义复核未完整传递号码筛查选项的问题。中文HTTP分块按UTF8连续解码，避免设置文字损坏。所有新功能保持现有凭据、会话与来源保护。

具体说明：[图片输入](GENERIC-VISION.md)、[素材库](MEDIA-LIBRARY.md)、[设置视图与矩阵](SETTINGS-VIEWS.md)。最终测试、公开清单和部署证据分别记录，未执行的真实服务场景不会列为通过。

## 前端开启路径收束

简易版识图从“选启用＋勾授权＋保存”收束为说明清楚的单个开关：用户主动点击即授权当前接收方并保存。详细范围与主动连接诊断仍在专业模式，不影响直接开启。新增忙碌防重复、明确错误回滚、未知结果读回、迟到及目标变化保护；不自动切换服务，不发送测试请求。模式按钮区分当前选择，并验证所有分区的小屏布局。
