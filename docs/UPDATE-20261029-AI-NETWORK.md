# 2026-10-29：AI 网络与草稿测试修复

- AI 模型和模型列表请求支持独立的旧行为、直连、环境代理、手动 HTTP/HTTPS 代理；默认不改变既有路由，不更改 QQ/NapCat 或进程全局网络。新模式需要 Node 24.14+，不增加 npm 依赖，不硬编码代理端口。
- 手动/环境代理地址拒绝内嵌认证信息；本机网络配置排除在公开清单之外。TLS 校验、API 凭据目标绑定和原有加密存储机制保留。
- 修复本机请求失败后结果框仍停在“正在测试”的问题。结果展示不再等待页面刷新，增加独立刷新截止时间、阶段耗时、操作编号、取消与迟到结果保护；不会自动重试。
- 后端测试截止时间覆盖本地预算等待及忽略取消的响应等待；草稿文字测试不再继承不适用的识图或群上下文外发开关。
- 官方 OpenAI 地址即使选择“自定义平台”，Chat Completions 仍发送 `max_completion_tokens`；其他兼容平台的 `max_tokens` 规则保留。三条旧官方地址断言按此契约更新，并增加禁止旧字段的断言，测试未删减或跳过。
