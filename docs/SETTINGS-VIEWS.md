# 设置视图与验收范围

默认简易模式保留日常开关、模型连接、会话范围、图片与素材、撤回和打卡的必要设置。专业模式展开缓存、队列、预算、完整频率与诊断。切换视图不保存、删除或重建控件，未保存输入仍在；视图偏好只保存在当前浏览器。

分区保存只提交相应字段，保留其他草稿和运行配置；全量API草稿保存的既有关闭AI行为会明确显示。素材、代理、筛查、图片范围各有独立保存入口。错误输入显示可操作原因；取消等待不冒称上游已停止。

号码/证件识别筛查与本地语义复核是独立可选项，默认关闭。前者用于已实现的文本/图片要求或结果检查；后者仅复核普通私聊文本，需已安装的本机模型。没有按健康、财务等话题词一律拒绝的规则。关闭这些选项不能关闭上游政策，也不关闭凭据脱敏、会话隔离、路径/URL、格式大小和权限保护。

## 设置清单

完整字段、保存入口与静态消费者列在[设置矩阵](SETTINGS-MATRIX.json)。清单覆盖AI、管理连接、代理、素材、撤回、逐群打卡及派生元数据；派生绑定与版本字段不是供用户手工编辑的设置。静态引用不等于执行过每条分支。

| --- | --- |

| 实际消费者 | AI队列/上下文、素材发送、撤回、打卡调度各模块测试；仅使用mock服务 |
| 非法输入、跨来源/路径与跨会话 | vision-source、private-privacy、media-library、product-settings等用例 |
| 取消、重复点击、未知投递和重启恢复 | AI生命周期、outbox、delivery-unknown、素材与打卡用例 |
| 简易/专业切换、草稿、页面重开和响应式 | 独立真实浏览器，合成配置与服务 |

维护诊断置于明确的专业入口，默认页面不展示色序、堆栈或原始测试字段；真实错误和未知状态不会被隐藏成成功。

回滚代码前若已在新版明确授权图片、而未有旧版要求的自检通过记录，应先在新版关闭图片输入并保存，再回退旧代码。不要用旧整份配置覆盖之后的用户改动。初次升级不改变图片或素材开关。

## 常用操作路径

| 操作 | 简易模式 |
| --- | --- |
| 开启主动参与 | 阅读卡片内当前接收方与群范围说明，在同一保存流程完成必要背景文字授权；实际就绪状态另行显示 |
| 开启/关闭识图 | 阅读当前模型外传说明，点一次开关即保存；不要求先自检 |
| AI 总开关、自动重发 | 顶部各自开关直接生效；仍受原连接与会话权限约束 |
| 暂停素材发送 | 素材分区的一次暂停操作 |
| 称呼、名单、接口、分群时间等编辑 | 改完后使用所在分区保存，保留其他分区草稿 |
| 引用、近期图片及复杂参数 | 专业模式展开编辑，保留完整配置能力 |

保存结果区分已保存、明确失败和结果未确认；未知时只读重查，不自动重复提交。此次没有更改模型协议、图片处理或其他后台业务规则。

## 主动参与的开关与实际状态

基础视图直接区分关闭、已启用但缺少背景文字授权、AI关闭、QQ未就绪、名单为空或已排除、队列等待及就绪。话题条件、冷却、预算或模型保持沉默会显示对应原因，不用笼统的“开关或范围未满足”掩盖。最后一次跳过可能来自本人或非候选消息，不会盖过已读回的当前全局条件。就绪不承诺发言，更不代表上游或QQ端到端成功。

首次授权使用既有本机授权入口，会清理临时上下文，并只处理之后的新群消息；不回填旧日志。保存前先检查已保存的服务、模型、群和成员范围，发生变化时提示重新核对，不偷偷补名单。只提交本区相对已加载值的修改，未编辑字段取最新配置；同一字段被其他页面修改则保留草稿并报告冲突。每次本机请求最多等待10秒；回执丢失后读回核对，不自动重复提交。授权已保存但参数未保存时明确显示部分完成。
