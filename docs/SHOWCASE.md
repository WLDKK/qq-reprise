# 界面展示：仅合成数据

这些PNG制作于官方群打卡面板加入前，来自当时的`ui.html`，由独立的临时本机服务和浏览器渲染；只增加了永久可见的合成预览横幅及英文水印，没有连接生产管理页。

图中没有演示新增打卡面板；该功能的合成浏览器流程验收与真实业务边界见[打卡说明](GROUP-SIGN.md)。
