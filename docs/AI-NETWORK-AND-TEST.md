# AI 网络配置与单次测试

回响 QQ 助手的模型生成和模型列表请求有独立网络层。它不会修改 Windows 代理、VPN、TUN、系统环境变量、全局 fetch/Agent，也不接管 QQ、NapCat、媒体下载或 OAuth 登录流程。API 地址仍填供应商地址，例如 `https://api.openai.com/v1`，代理地址填写在单独的网络设置中。

## 四种方式

| 方式 | 行为 | 最低版本 |
| --- | --- | --- |
| 保持旧行为（默认） | 继续使用原来的 fetch；不自动读取或保存新的代理配置。原有系统级路由或启动参数仍可能影响实际出口 | Node 22.4+ |
| 明确直连 | 为 AI 请求建立独立直连 Agent，不使用全局 Agent 或环境代理 | Node 24.14+ |
| 环境变量代理 | 仅在明确选择时读取助手进程的 HTTP_PROXY、HTTPS_PROXY、NO_PROXY；不读取 Windows 系统代理注册表或 PAC | Node 24.14+ |
| 手动代理 | 使用用户填写的 HTTP/HTTPS 代理，为 AI 请求建立独立 Agent | Node 24.14+ |

“明确直连”指不使用应用层代理；系统级路由或 TUN 仍可能影响出口，脚本不会绕过或关闭它们。

这些新模式使用 Node 内置的每 Agent `proxyEnv` 能力，不安装额外依赖，不调用改变全局代理的函数，也不需要打开进程全局的 `--use-env-proxy`。实现及最低边界参见 [Node 24.14 HTTP 文档](https://nodejs.org/download/release/v24.14.0/docs/api/http.html#built-in-proxy-support)。本轮实际运行环境是 Node 24.14.0；其他版本尚未联调。

手动模式只声明支持 **HTTP/HTTPS 代理协议**，不是 SOCKS 专用端口。端口应取自用户当前代理客户端的 HTTP/Mixed 监听设置，不使用项目作者的个人端口。HTTPS API 经代理隧道仍校验目标 TLS 证书，不关闭证书校验。

本版明确拒绝含用户名、密码、查询参数、片段或路径的代理 URL，不保存代理认证信息；环境变量中的认证 URL 也会被拒绝，不会静默删除认证再重试。可使用用户已有可信客户端提供的无认证回环 HTTP/Mixed 入口。不要把 API Key 填入代理地址。

环境模式优先使用小写变量；未提供 HTTPS_PROXY 时使用 HTTP_PROXY 作为 HTTPS 代理。ALL_PROXY/SOCKS 不在本版支持范围。NO_PROXY 支持规则由 Node Agent 处理；所有新模式都额外保证 localhost、127.* 和 ::1 等回环目标直连，不因遗漏 NO_PROXY 把本机连接转给代理。没有可用代理变量时返回明确错误，不静默转为直连。运行中进程的环境不因后来修改系统环境变量而自动更新。

## 保存与测试分开

1. 打开 AI 连接设置中的“AI 请求网络”。选择连接方式，必要时填写自己的无认证代理地址。
2. “测试当前草稿”使用本页 API 与网络草稿，不写入 API Key、API 配置或网络配置，不开启 QQ AI，也不发送 QQ 消息。
3. “仅保存 AI 网络设置”才写入本机私有的 `ai-network.json`。它不更换 API 凭据，不改变 AI、撤回或打卡开关。已有 AI 任务、测试或网络请求进行时会拒绝保存，不中途更换路由。
4. API 草稿的“保存”另有含义：保存绑定此 API 目标的密钥和设置，并保持 AI 关闭；需要时再单独启用。原有平台、地址、协议与凭据绑定检查保留。

`ai-network.json` 不属于公开源码或示例包。即使其中不允许认证信息，代理地址也属于本机连接资料，不要提交到 Git。

## 单次合成测试的边界

测试使用空聊天历史和固定的 `Reply exactly OK.` 文本，不读取真实 QQ 聊天。每次操作最多提交一次模型生成请求；没有自动重试、换 Key 或备用连接切换。读取模型列表是另一个手动外部请求，不自动执行。

页面显示本次操作的阶段和已等待时间。后端的整段截止时间覆盖预算等待、凭据准备、请求和流式读取；页面另有本机等待截止时间。结果先展示，页面状态刷新在后台独立限时，刷新失败不会把已返回结果变成“还在测试”。前置校验或本机 HTTP 错误也会结束运行状态并显示脱敏错误码/字段。

“取消本次测试”会停止本机等待并请求后端中止对应操作，旧页面不能取消不同编号的新操作，迟到结果不能覆盖新操作。**远端是否已停止以及是否计费无法据此确认**，界面不会声称取消等于退费，不会自动重发。

自定义输出预算会发送 `max_output_tokens`（Responses）或在官方 OpenAI 地址发送 `max_completion_tokens`（Chat Completions）；其他兼容平台仍用 `max_tokens`。选择“由平台决定”会省略输出预算。超时、字符数、每日任务数都不是硬金额上限；程序没有实现货币计费封顶。Chat Completions 流式请求当前不保证取得完整 usage。

普通 Responses 与 Chat Completions 的文字请求均有实现，不代表任何模型 ID、账户权限或赠送额度已经通过实际验证。工具界面里的模型名字不能直接当作 API 的合法模型 ID。OpenAI 预设选择 Responses；换格式不会自动解决网络、授权或额度问题。

## 已验证和未验证

离线 mock 覆盖四种网络方式、回环排除、认证 URL 拒绝、连接拒绝、HTTP 400/403/429、两种接口、预算等待、响应/流式停滞、取消及迟到结果、重复点击和刷新挂起。自建临时回环 HTTP 服务验证了独立 Agent、状态码及压缩响应处理。

本轮不使用生产凭据、不切换生产路由、不消费真实模型额度、不发真实 QQ 消息。真实代理 CONNECT/TLS 链路、供应商权限/计费和用户创建 Key 时的原始超时尚未完成联调，不能用离线通过宣称这些问题已恢复。
