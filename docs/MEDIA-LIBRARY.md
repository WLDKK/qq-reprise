# 本地图片与GIF素材库

## 支持范围

| 内容 | 本项目发送方式 | 边界 |
| --- | --- | --- |
| PNG、JPEG、静态WebP | OneBot image消息段 | 只读取主动导入的库内副本 |
| GIF | image消息段，保留原始GIF字节 | 实际动画显示仍取决于QQ/NapCat |
| QQ商城原生表情 | 当前未封装 | NapCat的mface需要独立标识和key，不能把普通GIF等同于全部商城表情 |
| 任意URL、本地路径、自动搜图或付费生图 | 不提供 | 模型不能借素材ID获得文件或网络访问权限 |

协议依据：[OneBot图片消息](https://github.com/botuniverse/onebot-11/blob/master/message/segment.md)、[NapCat消息兼容说明](https://doc.napneko.icu/develop/msg)。接口支持说明不等于已完成真实QQ客户端联调。

## 使用

“图片与素材”中选择并添加文件。只复制选中的文件，不扫描相册；可预览、改名和移除库内副本，原文件不受影响。默认素材发送、自动附图均关闭，群和私聊范围均为空。

先设置独立会话范围并保存开启，再勾选素材，可手动向所选会话发送。素材勾选变化保存后才影响自动选取。自动附图只在新AI文字回复取得消息回执后执行，和识图输入、撤回重发、打卡开关独立；不会追补旧回复。文字投递未知时不附图。

自动选取可按勾选顺序、随机或由AI按标签选择。AI只获得已选素材的ID与名称，不获得文件路径或图片像素；只能返回允许的ID，不能构造URL或任意路径。仅在对应会话已授权、功能开启时提供这些标签。涉及代码块的文字不会被粗暴删改。

## 可配置项

简易视图提供总开关、自动附图、群/私聊名单、选取方式、单次数量和间隔。专业视图另提供小时/24小时次数、单图/累计大小、素材数量/总空间、排队等待、队列容量与回执超时。0取消对应的本地频率或等待限制，原QQ/NapCat约束和共享发送队列仍生效。

单次最多8张、单图最多5MiB、累计最多20MiB；GIF有尺寸和结构校验。素材库最多1000项、512MiB，投递元数据最多10000条，均为资源边界。默认间隔30秒、每次1张，素材队列默认5项。普通已完成投递记录保留7天；未知结果不自动删除。达到元数据容量时停止新增投递，不丢弃未知记录。

## 投递状态与隐私

有效消息ID表示取得OneBot消息回执，不等于所有收件人已读。超时、无有效回执或连接结果不明显示未知，不自动重发；同一操作ID不重复提交。未知结果会阻止同会话自动附图，须自行核对后明确解除；解除不会重发旧消息。可取消尚未提交的项，已提交部分无法承诺撤销；暂停只影响后续素材发送。

库内文件、选择设置和投递记录都留在本机。元数据不保存图片Base64，不上传到GitHub。私有目录/文件为`media-library/`、`media-settings.json`、`media-library.json`、`media-deliveries.json`，已加入排除规则。备份时一并保留；图片发送与AI代理配置分离。
