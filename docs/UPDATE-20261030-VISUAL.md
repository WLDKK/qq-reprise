# 工作台视觉统一

山雾壁纸与蓝灰单强调色应用于AI、账户、名单、人物、图片素材、撤回及官方群打卡全部分区。内容面板使用实色，保存按钮、输入框、导航、错误和未知状态采用统一层级；手机保持完整导航及可读表单。

## 使用方式

日常使用简易模式，专业模式展开全部参数。切换不保存或丢弃草稿；原有分区保存、0值含义、外传授权、重复点击保护和未知结果读回均保留。主题不新增业务开关，不修改模型、代理、名单、素材或参与条件。

## 实现与依赖

样式集中在`ui-theme.css`，由本机页面内联加载；固定壁纸来自`ui-assets/workbench-wallpaper.jpg`。没有运行时外部图片请求，没有扩大CSP或新增npm依赖。原220个静态控件ID和处理逻辑保留，合并了晚注入的工作台与素材样式。壁纸[原许可](WALLPAPER-CREDIT.md)不由MIT替代。

升级需同时更新HTML、样式、管理服务与固定壁纸；保留私有配置、绑定、账本和自行添加素材。新版仍使用RAM对话缓存，正常受控重载后重新积累。
