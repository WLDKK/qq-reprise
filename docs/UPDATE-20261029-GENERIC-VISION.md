# 通用识图更新

- 为普通 API 接入 Responses `input_image` 和 Chat Completions `image_url`，保留原 Discovery 兼容。
- 视觉验证绑定服务完整基础地址、协议、模型和图片数量；文字测试、模型名称或列表不再被当成视觉能力证明。切换目标或提高数量后需重新验证。
- 支持一条消息中的多图、明确引用的同会话图片组和另行开启的同用户近期图片定位。多个独立候选仍需明确引用，不拼接无关历史图片。
- 独立保存图片数量、单图/总字节、下载与请求超时。默认保留 1 张与关闭的图片外发权限；不会改变现有 AI 网络配置。
- 合成验证显示所用已保存目标、张数、阶段和结果，可取消，拦住重复或并发测试，迟到结果不污染新配置；不自动重试或开启图片权限。
- 图片始终使用已验证的原 API 连接，账户池不为它切换服务。保留下载来源、重定向、格式、容量、会话和撤回取消保护；原始图片不进入后续模型历史或长期日志。

查看 [通用识图说明](GENERIC-VISION.md) 和 [测试记录](../TESTING.md)。离线通过不代表真实供应商/QQ 联调成功，复杂图片的识别质量及费用由实际模型和服务决定。
