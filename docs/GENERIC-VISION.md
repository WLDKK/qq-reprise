# 图片输入

图片输入和图片/GIF发送是独立功能。前者把授权会话里的图片发送给你配置的AI接口；后者只把你添加到本地素材库的文件发送给所选QQ会话。

## 开启

1. 在“模型与API”保存接口、协议、模型和连接方式。Responses和Chat Completions都有图文序列化实现，但任意模型名不等于支持图片。
2. 在简易视图“图片与素材”阅读开关旁的接收接口、模型和图片外传说明，点击“开启识图”即同意并保存；不需要再勾一次授权或点击保存。关闭同样一次点击。专业视图保留引用、近期图片和完整图片草稿的分区编辑。
3. 引用图片与同用户近期图片定位可以分别开启。引用必须来自同一会话，近期定位只选同用户同会话的一组图片，存在多个候选时会要求明确引用。

合成能力检查是可选诊断，不再作为普通图片功能的硬门槛。开启只记录图片外发同意，不伪造“模型已通过验证”。默认仍关闭，不会因安装、升级或检查成功而自动开启。更换接口、协议或模型会解除旧绑定，需重新确认接收方。

## 范围与限制

默认每条消息最多1张，可在专业模式调整到1～8张；单图最多5MiB，总计最多20MiB。下载、总等待、引用与近期定位独立配置。调整数量不会冒称已经测试更多图片，也不会自动开启外发。GIF等动态来源识图仅取静态帧，不代表读取完整动画。语音、视频和任意本地文件不是本功能的图片输入。

来源、格式、大小、URL重定向、本地/敏感地址和跨会话校验始终保留；API凭据不会作为图片要求或普通提示发送。图像本体不写入会话历史或诊断文件，也不自动补传无关历史图片。

## 可选专业诊断

专业模式的高级图片诊断只发送本机生成的色块图，每次点击一个请求，可能消耗供应商额度。尺寸、精度、同色序对照可选，不自动重试。结果分别说明HTTP接收、回答完成、样题匹配和图片外发状态。四个位置答对几处只描述该题，不是所有图片任务的能力认证。

若需对比小图影响，可复用上次色序，先只把64改为512、精度保持auto，其他参数不变；不要同时改模型、协议和提示后把差异归因于尺寸。需要真实上游请求时由使用者主动确认。`detail`的支持和处理随模型变化，见[OpenAI图像输入文档](https://developers.openai.com/api/docs/guides/images-vision)。本项目的离线测试不能证明供应商实际使用了像素。

诊断只为服务端生成的图保留白名单色序、PNG尺寸/摘要及上游自报模型。普通用户图片不新增指纹；原始回答、Key、认证头、图片Base64不进入新增诊断。旧失败不会自动变为成功，缺失证据不能追溯补造。

## 简易开关的保存反馈

开关只保存当前已配置端点、协议和模型的图片权限，不提交 API Key 草稿，不开启 AI 总开关或扩大聊天名单。待处理期间不接受重复点击；明确失败显示原因并保留实际状态。连接中断或本机等待超时表示保存结果未确认，不能当作已撤销或成功；“重新读取状态”只查询本机，不会重复提交。成功回执直接显示，不等待后台刷新。服务目标变化后旧回执不会替新目标显示开启。键盘和移动端可操作。
